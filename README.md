# ftir
Analiziram spektre nakon određenih vremenskih intervala. Tražim porast karbonilnog pika.
U folderu #data se nalazi prvi krug merenja; ulje je zagrevano na 120 i 140 stepeni.
U folderu #drugi_krug je praćenje ulja na sobnoj temperaturi.
Zadatak: svaki uzorak provući kroz colab i utvrditi promenu integrala karbonilnog pika.

Plan: zagrevanje na 200 stepeni i praćenje ftir na 30 min nakon hlađenja.
